STEP 1

URL を入力

TicketDive の公演ページURL（通常URL、短縮URL、またはイベントID）を上の入力欄に貼り付けます。

STEP 2

残席 & 詳細を確認

開場・開演時間、会場場所、出演グループ、各チケット券種（前方・一般・最前OPなど）の販売状況が即時表示されます。

STEP 3

カレンダーに登録

「URLコピー」を押し、iPhone カレンダーの「カレンダー購読」や Google カレンダーの「URLで追加」に貼り付けると自動登録されます。

開発者の方へ: OpenAPI 3.0 仕様に準拠した REST API を提供しています。Bot や独自ツールから直接 JSON / iCal を利用可能です。
